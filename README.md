# Smoky Zone

> Where Hustle Meets Spirit

Smoky Zone is an interactive portfolio and creative hub built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. It showcases personal engineering projects, freelance work, hardware repair craftsmanship, hobbies, culture, and an interactive studio audio visualizer.

## Features

- **Hero Experience**: Bold neon aesthetics with HUD accents and dynamic call-to-actions.
- **About Me**: Interactive philosophy showcase with modal exploration.
- **My Work**: Showcase grid covering Web Builder, Freelance Projects, Phone & Gadget Repairs, and Social Media Promotions with expandable modal details.
- **Hobbies & Music**:
  - Highlights on NYC inspiration, Bronx drill culture, and street party vibes.
  - Built-in studio audio visualizer powered by the Web Audio API with real-time frequency equalizer animation.
- **Contact & Connect**: Direct email, quick message submission form, and links to Instagram, WhatsApp, LinkedIn, X, Discord, TikTok, GitHub, and Telegram.
- **Futuristic HUD Aesthetics**: Precision neon accents (`#64ffda`), dark navy theme (`#0a192f`), smooth animations, and responsive mobile navigation.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS + Custom HUD layers
- **Icons**: Lucide React & FontAwesome CDN
- **Audio**: Web Audio API `AudioContext` & `AnalyserNode`

## Development

```bash
npm install
npm run dev
```

Server runs on `http://0.0.0.0:3000`.
