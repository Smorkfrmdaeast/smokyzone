# SMOKY ZONE – A Futuristic Blue-Themed Portfolio

Welcome to **Smoky Zone**, a glowing, immersive blue digital space where technology meets creativity. This portfolio is designed to showcase skills, projects, and passions with a sleek, modern, and professional aesthetic. Every pixel, hover, and section pulses with electric blue energy, providing a futuristic, high-tech experience.

This project is built purely with **HTML**, **CSS**, and **JavaScript**, demonstrating that simple technologies can deliver a high-tech, glowing, and interactive experience.

## 💙 Features

*   **Futuristic Blue Glow Aesthetic**: The entire site features a cohesive neon-blue theme, with glowing effects on text, buttons, and interactive elements.
*   **Custom Glowing Cursor**: A custom cursor follows mouse movements with a soft, neon-blue glow, enhancing the high-tech interface feel.
*   **Scroll-Reveal Animations**: Content smoothly fades and slides into view on scroll, creating a dynamic and engaging user experience.
*   **Fly-Out Navigation**: A sleek, right-hand fly-out menu provides instant access to all sections while maintaining a clean, minimal interface.
*   **Interactive Modals**: Clickable images in the "My Work" and "Hobbies" sections open in a modal with detailed descriptions, offering a professional and in-depth look at each item.
*   **Music Visualizer Bar**: An interactive music bar with a "Now Playing" display and a real-time countdown. The visualizer features neon-blue ripple waves that pulse to the rhythm of the music, creating an immersive, "gangy" vibe.
*   **Futuristic HUD Elements**: Section titles are styled with glowing corner brackets, mimicking a futuristic Heads-Up Display.
